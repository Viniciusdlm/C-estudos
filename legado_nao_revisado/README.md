# Exercícios antigos não revisados

Estes arquivos foram produzidos antes da trilha atual de estudos e utilizam assuntos que ainda serão revistos, como condicionais, vetores, strings e funções matemáticas.

Eles estão preservados como registro de evolução, mas não representam necessariamente conteúdos que já domino. Cada exercício será refeito quando o respectivo assunto aparecer novamente no roadmap.
